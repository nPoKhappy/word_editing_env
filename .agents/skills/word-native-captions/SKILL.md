# Word 原生圖表公式標號與目錄

此技能適用於 `D:\word_editing_env`。與 [word-editing](../word-editing/SKILL.md) 配合；既有文件的文字或樣式修改亦遵循對應 docx-text-ops / docx-design-ops。使用工作區 `.venv/Scripts/python.exe`，在匯入 Word COM 前設定 `TEMP`、`TMP` 為工作區 `.tmp`。

## 必須成立的結果

每個本次新增或重新製作的圖、表、公式，必須同時具有：

1. 經 Word「參考資料 → 插入標號」或其原生 `Range.InsertCaption` / `Selection.InsertCaption` 產生的自動標號。
2. 文件已定義的對應段落樣式；有「圖」「表」「式」樣式就必須使用。
3. 至少一處相關內文的實質說明，並以 Word「交互參照」或原生 `InsertCrossReference` 插入可更新、可跳轉的引用。

每次 DOCX 編輯完成後，必須更新主目錄及所有既有圖、表、公式目錄的完整內容與頁碼，確保新增圖表自動收錄。更新流程是交付前的必要步驟，不需使用者逐次另行提醒。

## 檢查原稿並規劃插入位置

使用者於 2026-10-23 明確指定的排版偏好：圖說置於 Figure 下方，表格標題置於 Table 上方；圖片與表格依可用寬度適當置中。獨立展示公式建議置中，公式編號靠右，以阿拉伯數字連續編號。圖說與表格標題全文一致，優先遵循期刊官方指南與當次編輯指示。這是一般排版偏好；僅翻譯等限縮範圍的工作，仍遵守使用者當次要求，不據此擴大修改其他版面。

使用者於 2026-10-23 再次指定：引用計畫書已有的圖時，直接插入原圖，不自行重繪或換成代理圖。保留原圖像內容；只有使用者另行明確要求重繪時才改畫。圖號先對照來源計畫書辨識，期刊稿則維持自身原生連續標號與交互參照，交付時可附來源對照。

- 除非使用者要求覆寫，另存副本；檢查標號標籤、SEQ 序列、章節編號方式、樣式、目錄欄位和修訂狀態。
- 沿用實際標籤與序列，不憑樣式名稱推定標籤。例如「式」是段落樣式，原稿公式可能以 `(` 為標籤、搭配 `)`，形成 `(13)`。
- 保留既有樣式定義、其他圖表、EndNote 欄位、書籤與文件關係。新段落確實套用段落樣式，不只修改局部文字外觀。
- 修訂的接受／拒絕遵循現有技能及針對該文件的使用者授權；先前測試副本的授權不延伸至其他文件。
- 每個新增項目都安排在有關的說明段落附近，通常先在內文介紹，再呈現圖表或公式。

## 插入圖、三線表及公式

- **圖**：插入實際圖片／圖形，標號在圖下方；對標號完整段落套用既有「圖」樣式，圖與圖說避免分頁分離。
- **表**：使用可編輯的 Word 原生表格，標號在表上方；對標號完整段落套用既有「表」樣式。三線表只保留頂線、表頭下線、底線；不要垂直線、外框或每個資料列的橫線。長表可重複表頭，避免單列跨頁。
- **公式**：使用 Word 原生 OMath 可編輯公式，對整段套用既有「式」樣式；公式置中，括號編號靠右。以該段可用版心寬度設定置中／靠右定位點，不能用一串空白對齊。
- 公式編號也必須先經 `InsertCaption` 產生，再將其原生標號移至公式同列右側。保留 SEQ 欄位，刪除原位置副本，避免重複計數。
- 新增文字遵守工作區字型：中文標楷體、英文／Latin 文字 Times New Roman。數學物件保留 Word 所需的數學字型與結構，不把公式改成普通文字或圖片。
- **禁止**手打圖／表／式的數字、以一般清單編號代替標號、自行拼製 XML 的 SEQ 欄位來冒充實際執行「插入標號」、或以固定數字偽裝自動標號。

使用 COM 時，讀取 [原生 Word 操作要點](references/native-word-operations.md)，尤其是可省略參數、公式標號移動與目錄更新順序。

## 每個項目必須在內文被提及

- 引用必須位於與該項目相關的敘述或解釋段落。例如：「如圖〔交互參照〕所示，……」「表〔交互參照〕列出……」「依式〔交互參照〕計算……」。標籤包含與否依實際參照選項調整，避免「圖圖 3」等重複。
- 使用 `InsertCrossReference` 指向對應原生標號；選取完整標號或僅標籤與編號，依文意選擇。公式需要括號時，保留括號或在參照數字外加括號，數字本身不可手打。
- 圖說、表題、公式右側編號、主目錄、圖表目錄，都**不算內文提及**。
- 不以額外的「全部圖表公式引用清單」作為唯一提及；說明段落必須解釋該項目與內容的關係。不得捏造結果以補出引用。
- 建立本次項目與內文參照的對照清單，以實際欄位／書籤連結驗證。存在外觀相同的文字，不等於交互參照成立。
- 移動或刪除項目後修正相關引用；不得留下孤立標號、錯誤來源或已不存在的項目。

## 每次完成後自動更新目錄

1. 在 Word 完成所有內容、樣式與排版修改，再更新相關 SEQ 標號。
2. 更新本文交互參照 REF／PAGEREF，確認指向仍有效，再重新分頁。
3. 更新主目錄與全部既有圖、表、公式目錄的**完整內容**，不能只更新頁碼。使用各目錄物件 `Update()`；不是只呼叫 `UpdatePageNumbers()`。
4. 依實際 caption 標籤建立／維持原生圖目錄與表目錄。既有目錄若以 TOC 欄位搭配 `\c` 或自訂樣式產生，也要完整更新，不重建成手打清單。
5. 論文／報告若有本次圖／表但缺少相應目錄，在既有目錄區或合適的前置位置建立原生自動圖目錄／表目錄。沿用文件組織及格式。期刊稿依已確認的期刊結構；若計畫不含論文式目錄，不額外加入，而在 QA 中將不存在的目錄標為不適用。已有公式目錄則更新；使用者要求公式目錄時才新增公式目錄。
6. 主目錄沿用原有章節層級／篩選規則；圖表由專用目錄收錄，不為了「自動擴充」將所有 caption 強制改成章節標題。
7. 重新分頁，再刷新目錄頁碼及頁碼交互參照；如果目錄擴充造成頁碼改變，重複有限次直至頁碼穩定。最多三輪仍不穩定就診斷原因，不宣稱已完成。
8. 儲存最終 DOCX，重新開啟並核對新增項目已收錄且頁碼符合實際位置。

更新欄位時只操作相關標號、交互參照及目錄，避免無差別更新 ADDIN EN.CITE／EN.REFLIST 等 EndNote 欄位。使用者沒有要求引文變更時，保留其原樣。

## 交付前驗證

- 「已套用圖／表樣式」不等於版面完成。先檢查樣式的實際定義、直接格式、段前段後、縮排、行距與分頁。圖像段落使用容納整張圖的行距，避免固定行高裁圖；圖說保持獨立可編輯文字，短標題與必要說明，不把冗長內文塞進 caption。
- 圖下標號與圖像保持同頁，表上標號與表頭保持相連；圖說不可被裁斷、被頁界拆走或留下過大的圖像白邊。短表整體保持同頁；長表重複表頭、單列不跨頁，避免最後一列獨自落在下一頁。表格保留 12 pt，不為塞版縮字。
- 在實際插入寬度檢查圖中文字、上下標、箭頭與線條。缺字方框、交叉或懸空箭頭、模糊截圖都須修正；參考圖只沿用視覺組織，不搬入其研究變數、資料量或已驗證成果。
- 全稿圖表用同一套可讀的對齊、間距與標號格式；正文繼續符合指定期刊的行距。這些版面選擇是本機執行規則，不能冒稱期刊未明列的硬性數值。

- 每個本次圖／表／公式均有唯一原生 SEQ 標號、正確段落樣式，以及至少一處目錄以外的相關本文交互參照。
- 更新後標號順序與顯示值正確；交互參照能跳轉至實際項目，無「找不到參照來源」「未定義書籤」等錯誤。
- 新增圖／表逐項出現在相應原生目錄，標題、編號、頁碼與正文一致。不能以「已呼叫更新」當作收錄成功證據。
- 使用 Word 實際匯出 PDF，渲染並檢查頁面；確認三線表、圖說、公式編號、正文引用和目錄沒有溢出／錯位。
- 交付時簡述新增項目、內文引用及目錄更新驗證結果。若 Word 原生插入、目錄更新或渲染無法完成，明確指出未完成項目，不以 XML／靜態文字檢查冒充成功。
- 對於本次範圍以外的舊有缺失，避免擅自全文重寫；若它阻礙本次標號／目錄的正確性，做必要修復並說明範圍。
